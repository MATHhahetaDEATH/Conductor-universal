Mobile Demo Apps
================

The ``iosapp/`` and ``androidapp/`` directories are small platform entry points;
the shared Tauri 2 frontend and Rust login command live in ``MobileApp/``.

Requirements
------------

* Node.js and npm
* Rust with the target for the selected platform
* Xcode for iOS simulator/device builds
* Android Studio with Android SDK and NDK for Android builds

Install the shared frontend dependencies once:

.. code-block:: bash

    cd MobileApp
    npm install

Run the platform app from its entry directory:

.. code-block:: bash

    cd iosapp
    npm run dev

    cd androidapp
    npm run dev

The login screen accepts a server IP or URL, username, and password. A server
entered as a bare IP is normalized to ``http://<ip>:8678``. The Rust command
posts credentials to ``/api/user/login`` and returns the session token. On
success, the app navigates to the WebApp with the token in a URL hash. The WebApp
consumes the hash before its login guard runs, stores the session, and removes
the token from the visible URL.

The mobile device must be able to reach the WebApp and its ``/api`` proxy at the
configured address. Local HTTP is enabled for development on trusted networks;
use HTTPS when exposing a server beyond a trusted LAN.

Build debug packages with the platform wrapper:

.. code-block:: bash

    cd iosapp
    npm run build

    cd androidapp
    npm run build

The iOS wrapper targets an unsigned simulator build. The Android wrapper builds
a debug package. Tauri-generated Xcode and Android Studio projects are kept under
``MobileApp/src-tauri/gen/`` and can be regenerated by the Tauri CLI.
