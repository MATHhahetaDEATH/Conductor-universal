# LLM Provider Docs

This directory contains the split documentation for the `llm_provider` core plugin.

- [architecture.md](./architecture.md): internal architecture, module responsibilities, queueing, routing, subprocess isolation, and maintenance notes
- [plugin_api.md](./plugin_api.md): how other plugins should depend on and call `llm_provider`, with detailed guidance for `t1`, `t2`, `t3`, `vl`, and `eb`
